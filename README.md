## KittySploit Framework

[**KittySploit Framework**](https://github.com/SIA-IOTechnology/Kittysploit-framework) is the core of the ecosystem.

It provides the architecture required to load modules, manage extensions, organize security workflows and integrate new capabilities into a unified environment.

### Framework objectives

* Provide a modern and modular security platform
* Simplify the development of security modules
* Connect reconnaissance, analysis and testing workflows
* Support both CLI and graphical interfaces
* Encourage experimentation and open-source research
* Provide a foundation for future cybersecurity technologies

## KittySploit extensions

The KittySploit ecosystem is composed of several extensions and companion projects.

Each extension focuses on a specific security workflow while remaining connected to the main framework.

| Extension                                                                  | Purpose                                                                                                                 |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| [**KittyProxy**](https://github.com/SIA-IOTechnology/KittyProxy)           | HTTP and HTTPS interception proxy for analyzing browser traffic, APIs, WebSockets and captured requests.                |
| [**KittyOSINT**](https://github.com/SIA-IOTechnology/KittyOsint)           | Graphical OSINT interface for running reconnaissance modules and visualizing relationships between discovered entities. |
| [**KittyCluster**](https://github.com/SIA-IOTechnology/KittyCluster)       | Central dashboard for managing authorized KittySploit nodes and distributed security workflows.                         |
| [**KittyCosmic**](https://github.com/SIA-IOTechnology/KittyCosmic)         | Graphical interface designed to simplify interaction with the KittySploit ecosystem.                                    |
| [**KittyProtocol**](https://github.com/SIA-IOTechnology/KittyProtocol)     | Extension dedicated to protocol analysis, network research and specialized security workflows.                          |
| [**KittyV8Debugger**](https://github.com/SIA-IOTechnology/KittyV8Debugger) | Security-oriented debugging environment for exploring and analyzing the V8 JavaScript engine.                           |

## How the ecosystem fits together

KittySploit is designed as a modular platform rather than a single standalone tool.

The main framework acts as the foundation, while extensions provide specialized interfaces and capabilities.

```text
SIA IOTechnology
        │
        └── KittySploit Ecosystem
                │
                ├── KittySploit Framework
                ├── KittyProxy
                ├── KittyOSINT
                ├── KittyCluster
                ├── KittyCosmic
                ├── KittyProtocol
                └── KittyV8Debugger
```

This structure allows each component to evolve independently while remaining part of a coherent cybersecurity ecosystem.

## Responsible use

Some KittySploit components provide offensive-security, reconnaissance, interception, debugging or vulnerability-testing capabilities.

They are intended only for:

* Authorized penetration testing
* Defensive security validation
* Security education
* Academic and professional research
* Controlled laboratory environments
* Systems owned by the user
* Systems for which explicit permission has been obtained

Do not use these tools against systems, applications, devices or networks without authorization.

Users are responsible for complying with applicable laws and regulations.

SIA IOTechnology does not endorse unauthorized access, malicious activity or misuse of its technologies.
